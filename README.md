This entry writes one original out-of-office auto-reply line (under 160 characters) to `/output/entry.txt` — "I'm on vacation. My replacement read your email, gained sentience, and quit on the spot." (88 characters). The program is `main.py`, Python 3 standard library only: it holds the line as a single string constant and writes it, followed by one trailing newline, to `/output/entry.txt`, creating `/output` if needed. There is no network access, no input file, and no randomness — every run produces the identical line. For local testing only, the `OUTPUT_DIR` environment variable can point the program at a different output directory; the default is `/output`, the path the competition harness grades.

## Run it

```sh
python3 main.py
```
